# Transcritical O2 Injection 2D

## 物理模型

### 几何
- 轴对称2D域
- 喷嘴直径: d = 1 mm
- 下游长度: L = 20d = 20 mm
- 径向范围: R = 10d = 10 mm

### 边界条件
- 入口 (喷嘴): O2, T=100K, p=6.0 MPa (超临界)
- 共流 (环境): N2, T=300K, p=0.5 MPa (亚临界)
- 出口: 压力出口 p=0.5 MPa
- 轴线: 对称
- 远场: 自由流

### 参考实验
Mayer et al. (1998) - Transcritical oxygen injection
- 密度峰值位置
- 密度衰减曲线
- 混合层厚度

## 网格

结构化网格:
- 轴向: 200 cells (喷嘴附近加密)
- 径向: 100 cells (剪切层加密)
- 总计: 20,000 cells

## 预期现象

1. 超临界O2喷出 (类液体密度 ~1000 kg/m³)
2. 快速膨胀和减压
3. 与亚临界N2混合
4. 密度梯度驱动的涡结构
5. 下游气化

## 验收标准

- 轴线密度峰值位置误差 < 10%
- 密度衰减趋势一致
- 混合层厚度合理
