# CoolProp 7.2.0 TP-flash reference

`pr_tp_flash_coolprop72.csv` is a frozen external thermodynamic reference generated by:

```text
python tools/generate_pr_tp_flash_coolprop72.py
python tools/generate_pr_tp_flash_coolprop72.py --check
```

The generator requires exactly CoolProp 7.2.0, writes ASCII with LF line endings, uses
17-digit scientific notation for every floating-point field, and sorts records by
`case_id`. `--check` regenerates the bytes in memory and fails if the checked-in CSV is
not bitwise identical.

The pure-Oxygen rows contain fixed-pressure saturation states at 2 MPa and 4 MPa. The
6 MPa rows are explicitly supercritical-isobar samples because 6 MPa exceeds the
CoolProp Oxygen critical pressure (`5.046410521187217 MPa`); they are not saturation
records. CoolProp enthalpy uses its own reference convention, so latent heat and
state-to-state differences are more portable than absolute enthalpy.

For the 50/50 molar Oxygen/Propane row, `quality_mole` is the vapor mole fraction,
`x_*` and `y_*` are liquid and vapor mole fractions, and `rho_mass_kg_m3` and
`h_mass_j_kg` are overall mass-specific properties. The generator verifies the molar
lever rule. CoolProp 7.2.0 provides only default reducing parameters for this binary
pair (`betaT=gammaT=betaV=gammaV=1`, `F=0`) and no fitted binary departure term.
Therefore this mixture row is a reproducible HEOS implementation reference, not an
experimental-accuracy validation point or an endorsement of the mixture model.
